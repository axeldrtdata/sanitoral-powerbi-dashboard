# Users and user stories

Taken from the Product Strategy Canvas, written from the scoping note with the Project Management Office.

| User | Story |
| ---- | ----- |
| **CEO** | As the CEO, I want an overall view of the performance of all projects, so that I can decide whether each one continues or stops. |
| | As the CEO, I want to be alerted when a project exceeds a 15% gap on costs, delays or deliverables, so that I can react quickly. |
| | As the CEO, I want to filter by project type, region and period, so that I can look at performance from different angles. |
| **Regional director** | As a regional director, I want to follow the indicators of the projects in my region, so that I can supervise their progress. |
| | As a regional director, I want to be alerted on the projects of my region with a performance gap (15% +/-), so that I can step in with the country directors concerned. |
| | As a regional director, I want a map of the countries where projects are most delayed, so that I can spot the problem areas. |
| **Country director** | As a country director, I want the detail of the indicators (costs, delays, deliverables) of my projects, so that I can take corrective action. |
| | As a country director, I want to compare planned and actual for each indicator (15% +/-), so that I can measure the gaps and prioritise my actions. |
| | As a country director, I want the detail of each project by phase, so that I can locate the problems, or what works well, precisely. |

## Business rules from the scoping note

- Three indicators drive the activity: **costs, deadlines, deliverables**.
- A gap of **15%** between planned and actual on any of them must alert the directors.
- Marketing projects have **4 phases** (1 to 4), IT projects **6 phases** (A to F), and all phases matter equally.
- The data covers projects from **2018 to early 2022**, in **52 countries** grouped in **4 regions**.
